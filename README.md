# Pacifique Liyana Ishimwe

A personal portfolio and product work website showcasing experience in product management, digital platforms, AI-powered services, and impact-focused product delivery.

The site includes an overview of Pacifique’s background, a dedicated product work section, selected case studies, strategy frameworks, experiments, prototypes, and contact information.

## What’s inside

- Personal introduction and professional summary
- Product work and case studies
- Product strategy and experimentation examples
- Timeline and skills/tooling overview
- Contact and LinkedIn links
- PDF export option for the work page

## About this project

This repository powers the public GitHub Pages site for Pacifique Liyana Ishimwe. It is designed as a lightweight, responsive portfolio that presents work samples and product thinking in a clear, visual format.

## Tech stack

This project is built with:

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Router
- Through lovable
